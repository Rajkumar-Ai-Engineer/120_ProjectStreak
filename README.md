## Important catalogue and verification notes

1. **120 catalogue entries are not the same as 120 verified implementations.** This README records the intended project list from the workbook. Repository implementation status must be established from source files, notebooks, assets and project-level documentation.
2. The workbook contains 120 project-title rows. Its final 12 rows have blank project-number cells; their IDs 12–1 above are inferred from their position in the descending sequence.
3. The title **“Movie Recommendation System using SVD”** appears twice in the final 12 workbook rows. Both source rows are preserved as entries 10 and 9; they are flagged as a likely duplicate and should be reconciled against the original source before treating them as two distinct implementations.
4. Existing repository indexes may retain older IDs, folder labels, supplemental candidates or image/PDF-only references. Those are evidence records, not authority to renumber this workbook-derived catalogue.
5. Project screenshots, diagrams and PDFs are useful references, but do not by themselves prove that code, datasets, model weights or dashboards are present.
6. Some project titles combine techniques or domains (for example, CNN-based classification within the requested Deep Learning block). The grouping above follows the requested sequential ID ranges exactly.
7. Relative links point to the current repository documentation indexes. A link to a domain index does not claim that every catalogue entry has a matching source folder.
