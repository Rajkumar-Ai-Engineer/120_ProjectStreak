## Counting principles

1. A project is counted once based on its independent purpose and implementation boundary.
2. Datasets, model artifacts, generated outputs and nested components are not separate projects.
3. Source-bearing folders, images and PDFs are distinct evidence classes.
4. Similar names do not establish equivalence; image references do not prove source implementation.
5. Conflicting IDs are preserved and flagged rather than silently renumbered.
6. The target of 120 is not treated as a verified total until the original catalogue is fully reconciled.
