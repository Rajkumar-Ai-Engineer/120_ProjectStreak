# AI Image Captioning for Social Media Content

**Source:** [58_—_ai_image_captioning_for_social_media_content_using_gemini.py](58_—_ai_image_captioning_for_social_media_content_using_gemini.py)

## Purpose
Generate an image caption using Microsoft's GIT image-captioning model, then use Google's Gemini model to draft social-media content based on that caption.

## Observed flow
1. Load `microsoft/git-base-coco` through Transformers `AutoProcessor` and `AutoModelForCausalLM`.
2. Read the hard-coded image `/content/O1.jpg`.
3. Generate and decode an image caption.
4. Read `gemini_api_key` from Google Colab userdata.
5. Call `gemini-2.0-flash` to generate Instagram, WhatsApp and LinkedIn content.
6. Print the response.

## Dependencies
Transformers, PyTorch, Pillow, Google Gen AI SDK and Google Colab userdata.

## Important distinction
The image caption is generated by the GIT model. Gemini is used for the subsequent social-copy generation; the project name should not imply Gemini performs the initial visual captioning.

## Limitations
- Hard-coded Colab image path and Colab-specific secret retrieval.
- No caption quality evaluation or grounding check.
- No structured per-platform output contract, length validation, retry logic, tests or UI/API.
- Generated social copy may contain details not supported by the image/caption and needs review.

## Security
Use secret storage; never commit API credentials. The separate Detectron2 source in this directory tree contains a hard-coded Roboflow credential and requires rotation.

## Verification
Static inspection only; neither model nor Gemini API was executed.
