# AI Image Captioning for Social Media Content

**Reference label:** 58 — AI Image Captioning for Social Media Content using Gemini  
**Source:** [58_—_ai_image_captioning_for_social_media_content_using_gemini.py](58_—_ai_image_captioning_for_social_media_content_using_gemini.py)

## Purpose
Generate an image caption with Microsoft's GIT image-captioning model, then ask Google's Gemini model to turn that caption into social-media copy.

## Observed pipeline
1. Load `microsoft/git-base-coco` using Transformers `AutoProcessor` and `AutoModelForCausalLM`.
2. Read the hard-coded image `/content/O1.jpg`.
3. Generate and decode an image caption.
4. Read `gemini_api_key` from Google Colab userdata.
5. Call `gemini-2.0-flash` with a prompt requesting Instagram, WhatsApp and LinkedIn content based on the caption.
6. Print the response.

## Dependencies and services
- `transformers`, `torch`, `Pillow`
- Google Gen AI Python SDK
- Google Colab userdata for secret retrieval
- Gemini API access

## Important security finding
The checked-in source includes a literal API credential in the separate Detectron2 project, not in this captioning script. Treat committed credentials as exposed: revoke/rotate them and use secret storage. Never copy credentials into documentation or commits.

## Current limitations
- The image path is fixed to Colab.
- The captioning model is COCO-pretrained; domain-specific caption quality is not evaluated.
- Gemini output is not validated for factual accuracy, platform-specific length, or safety.
- No structured output, retries, rate-limit handling, tests, or UI/API is present.
- The filename mentions Gemini but the image caption itself is generated by GIT; Gemini generates the downstream social copy.

## Run context
Colab-oriented script; configure the image and Colab secret before running. Execution and API behaviour were not independently tested during this documentation pass.
